# 承诺追踪

## 目标

让 Agent 能回答“我答应了谁什么”“谁还欠我什么”“哪些承诺快到期/已逾期”，并为催办、提醒、会议跟进提供结构化依据。

## 用户故事

- 作为用户，我希望查看所有待跟进承诺、截止日期和 follow-up，不需要逐条翻聊天。
- 作为用户，我希望按项目或人筛选承诺。
- 作为用户，我希望 Agent 能区分“我欠别人”和“别人欠我”的大致方向，即使第一版只是保守启发式判断。

## 接受标准

- 新增 `CommitmentTrackerTool`，支持：
  - `list`：列出承诺/截止日期/跟进事项。
  - `summary`：输出逾期、即将到期、未来事项、按人分组和下一步建议。
- 数据来源为 `AgendaStore` 中的 `commitment/deadline/follow_up`。
- 可按 `project`、`person`、`status`、`windowDays` 过滤。
- 只读，不修改 Agenda；创建/更新仍由 `AgendaTool` 完成。
- 找不到匹配时输出空列表和摘要，不编造。
- 单元测试和 replay eval 覆盖基本查询。

## 非目标

- 不在本阶段做 LLM 自动抽取承诺。
- 不自动发送催办消息。
- 不强制准确识别所有中文语义方向；第一版只做可解释启发式。

## 环境假设

- 承诺、截止日期和跟进事项已经由对话或知识捕获写入 `AgendaStore`。
- 人和项目上下文可从 `OfficeContextStore` 读取，用于匹配和分组。
